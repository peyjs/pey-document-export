# pey.document-export — معرفی

## این پروژه چیست؟

این افزونه متن‌های Markdown برنامه را به خروجی قابل‌بردن بیرون تبدیل می‌کند: یا یک سند HTML کاملِ فارسیِ راست‌به‌چپ با تم انتخابی، یا یک بستهٔ فشرده که چند فایل Markdown را با پوشه‌بندی‌شان یک‌جا نگه می‌دارد.

## چه مشکلی را حل می‌کند؟

نوشته‌ها داخل برنامه می‌مانند و کاربر راه تمیزی برای بردنشان بیرون ندارد. اگر هر صفحه خودش خروجی بسازد، هر کدام سندی با ظاهر و ساختار متفاوت تحویل می‌دهد و فایل‌ها معمولاً شکل یک سند مستقلِ خوانا را نمی‌گیرند.

## چه می‌کند و چه نمی‌کند؟

می‌کند:
- متن Markdown را به یک سند HTML مستقل تبدیل می‌کند که بدون برنامه هم در مرورگر باز می‌شود و فارسی و راست‌به‌چپ است.
- سه تم روشن، تیره و قهوه‌ایِ کم‌رنگ برای سند خروجی می‌گذارد.
- چند متن Markdown را با نام و مسیر پوشه‌شان در یک بستهٔ فشرده کنار هم می‌گذارد.
- نام فایل خروجی را از عنوان سند می‌سازد و نام‌های تکراری را متمایز می‌کند.

نمی‌کند:
- خروجی غیرمتنی نمی‌دهد؛ PDF، Word و اکسل از کارهای آیندهٔ این افزونه نیستند.
- خودش Markdown را رندر نمی‌کند؛ این کار با افزونهٔ Markdown برنامه است و بدون آن، خروجی گرفتن با پیام روشن شکست می‌خورد.
- هیچ چیز را ذخیره نمی‌کند؛ نتیجهٔ هر درخواست همان‌جا به برنامه داده می‌شود.
- محتوای سند را دگرگون نمی‌کند؛ همان متنی که می‌گیرد، همان را خروجی می‌دهد.

## چطور کار می‌کند؟

۱. برنامه متن Markdown را به افزونه می‌دهد و نوع خروجی را انتخاب می‌کند: سند HTML یا بستهٔ فشرده.
۲. افزونه متن را با افزونهٔ Markdown برنامه به قطعهٔ آمادهٔ نمایش تبدیل می‌کند.
۳. برای سند HTML، افزونه آن قطعه را داخل یک قالب کامل می‌گذارد: زبان فارسی، جهت راست‌به‌چپ، تم انتخابی و استایل‌ها همه داخل خود فایل.
۴. برای بستهٔ فشرده، هر متن جداگانه به فایل Markdown تبدیل می‌شود؛ نام و مسیر پوشه‌اش از عنوان و مسیر خودش می‌آید و مسیر تکراری شماره می‌گیرد.
۵. نتیجه با نام فایل مناسب و نوع محتوای درست به برنامه برمی‌گردد تا برنامه آن را دانلود کند.

## یک مثال واقعی

کاربر ده یادداشت سفرش را با پوشه‌های «تهران» و «اصفهان» نوشته و می‌خواهد همه را ببرد. برنامه همهٔ متن‌ها را به افزونه می‌دهد؛ یک بستهٔ فشرده می‌گیرد که داخلش پوشه‌ها و فایل‌های متن با همان چینش است. یادداشت دیگری را با تم تیره به شکل سند HTML می‌برد و روی هر رایانه‌ای در مرورگر باز می‌کند: همان تم، همان راست‌به‌چپ، همان هایلایت‌ها.

## اگر چیزی خراب شود چه می‌شود؟

- اگر افزونهٔ Markdown در دسترس نباشد، برنامه با پیام روشن می‌گیرد که خروجی ممکن نیست؛ هیچ فایلی ساخته نمی‌شود.
- اگر تم انتخابی ناشناخته باشد، درخواست با پیام روشن رد می‌شود.
- اگر شکل ورودی درست نباشد، مثلاً به‌جای فهرست سندها چیز دیگری بیاید، پیام روشن می‌گیرد.
- اگر ساخت بستهٔ فشرده وسط راه شکست بخورد، خطا به برنامه می‌رسد و آرشیو نیمه‌ساخته‌ای بیرون نمی‌دهد.

## به چه چیزهایی وابسته است؟

به افزونهٔ Markdown برنامه: تبدیل متن به شکل نمایش‌پذیر از آن می‌گذرد و بدون آن، این افزونه هیچ خروجی‌ای نمی‌سازد و هر درخواست را با پیام روشن رد می‌کند.

## واژه‌نامه

- **Markdown:** قالب سادهٔ نوشتن متن با نشانه‌ها، مثل `#` برای عنوان.
- **افزونهٔ Markdown:** افزونه‌ای که متن Markdown را به شکل نمایش‌پذیر تبدیل می‌کند (در این برنامه با نام `pey.markdown`).
- **سند مستقل:** فایلی که همهٔ استایل‌ها و قالبش داخل خودش است و به برنامهٔ سازنده نیاز ندارد.
- **تم:** ترکیب رنگ آمادهٔ سند، مثل روشن یا تیره.
- **بستهٔ فشرده:** یک فایل zip که چند فایل را کنار هم نگه می‌دارد.
- **پارس‌نشان:** افزونه‌های فارسی Markdown، مثل شعر و فهرست فارسی، که در رندر به‌کار می‌روند.
